# ระบบวันลาอิเล็กทรอนิกส์ (Leave Management System)

ระบบบริหารจัดการวันลา ทะเบียนกำลังพล และออกเอกสารใบลาอัตโนมัติตามแบบฟอร์มทางราชการ รองรับการซิงค์ข้อมูลกับ Supabase Cloud Database

## ✨ คุณสมบัติหลัก (Key Features)

1. **แบบพิมพ์ใบลามาตรฐานทางราชการ (กองทัพอากาศ / หน่วยงานราชการ)**
   - แบบ ๗: ใบลาพักผ่อน (ทั้งแบบช่วงวันที่ต่อเนื่อง และแบบระบุวันไม่ต่อเนื่อง)
   - แบบ ๓: ใบลาป่วย (พร้อมระบบข้อมูลแพทย์และการรักษา)
   - แบบ ๖: ใบลากิจส่วนตัว
   - มีระบบจัดวางแบบฟอร์มและเส้นจุด Dot-leader สำหรับปริ้นต์ขนาดกระดาษ A4 ได้ตรงมาตรฐาน

2. **ระบบทะเบียนกำลังพลและสถิติวันลา**
   - คำนวณวันลาคงเหลือ อัตราการลาสะสม และโควตาวันลาอัตโนมัติ
   - สรุปสถิติภาพรวมผ่าน Dashboard แยกตามบุคคลและหน่วยงาน

3. **ทะเบียนคุมใบลา (Leave Register)**
   - ตรวจสอบสถานะใบลา (อนุมัติ, รออนุมัติ, ไม่อนุมัติ)
   - ค้นหาและกรองข้อมูลตามประเภทและสถานะ
   - อนุมัติ / ไม่อนุมัติ / ลบใบลา พร้อมคืนโควตาวันลาแบบ Real-time

4. **ระบบบัญชีผู้ใช้และสิทธิ์การเข้าถึง (RBAC)**
   - รองรับบทบาท: Superadmin, Admin, User
   - ตรวจสอบสิทธิ์การเข้าถึงแต่ละเมนู
   - บันทึกประวัติการใช้งาน (Audit Logs)

5. **ระบบคลาวด์ Supabase Cloud Database**
   - ซิงค์ข้อมูลข้ามเครื่องแบบ 2-way real-time
   - ทำงานแบบ Hybrid (ออฟไลน์ใช้ LocalStorage / ออนไลน์เชื่อมต่อ Supabase)

## 🚀 การติดตั้งและใช้งาน (Getting Started)

1. เปิดไฟล์ `index.html` ผ่านเว็บเบราว์เซอร์ (Google Chrome, Microsoft Edge, Opera ฯลฯ)
2. หรือรันผ่าน Local HTTP Server:
   ```powershell
   # ตัวอย่างรันเซิร์ฟเวอร์บนเครื่อง
   python -m http.server 8080
   # หรือเปิด index.html ได้โดยตรง
   ```
3. (ตัวเลือก) เชื่อมต่อ Supabase:
   - นำโค้ดจาก `supabase_schema.sql` ไปรันใน SQL Editor บน Supabase Dashboard
   - นำ Project URL และ Anon Key มากรอกในหน้าการตั้งค่าของระบบ
